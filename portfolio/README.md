# Gabriel Leal — Portfolio

Personal portfolio for front-end development, product interfaces, and selected projects. Built with React, TypeScript, and Vite, with GSAP and Lenis for motion and scrolling.

## Local development

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

The generated site is in `dist/`. The repository includes a Vercel configuration for deployment.
